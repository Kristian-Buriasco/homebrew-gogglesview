# homebrew-gogglesview

Homebrew tap for [GogglesView](https://github.com/Kristian-Buriasco/gogglecast), a free macOS live view for DJI Goggles 3.

```bash
brew install --cask Kristian-Buriasco/gogglesview/gogglesview
```

Apple Silicon, macOS 14 or later. The app isn't notarized; the cask's caveats explain the first launch.
